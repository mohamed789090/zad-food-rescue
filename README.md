# مَنَصَّة زَادْ (ZAD) — لإنقاذ فوائض الطعام والاستدامة 🌾
> **مشروع تخرج نظم ومعلومات إدارية (MIS) — High-End Web Application**

منصة رقمية حديثة تربط بين سلاسل الإمداد الغذائي (المطاعم، الفنادق، والمخابز) بالمستهلكين والجمعيات الخيرية لإعادة توجيه فوائض الأطعمة الطازجة والسليمة 100% بأسعار مخفضة أو عبر تبرعات مجانية مخصصة للمبادرات الإغاثية، مع استلام ذاتي (Self-Pickup) مباشر بالكود، واحتساب آلي لمؤشرات الأثر البيئي والمجتمعي.

---

## 🎨 نظام التصميم الموحد (High-End Design System)

- **لوحة الألوان:** 
  - درجات الأخضر الزمردي والزيتي الغني (`#065f46`, `#047857`, `#059669`) للتعبير عن الطاقة الحية والاستدامة البيئية.
  - لمسات ذهبية وعنبرية دافئة (`#f59e0b`, `#d97706`) للعروض الخاصة والخصومات والتنبيهات.
  - خلفيات نظيفة نقية مريحة للعين (`#f8fafc`).
- **التصميم الزجاجي (Glassmorphism):**
  - بانر رئيسي (Hero Section) بزجاج ضبابي شبه شفاف مع عدادات أثر عائمة.
  - شريط تنقل علوي ثابت (Sticky Navbar) بضبابية خلفية حديثة (`backdrop-filter: blur(14px)`).
- **التفاعل الحركي والميكرو-إنتركشن (Micro-interactions):**
  - **نظام إشعارات عائم (Floating Toast Notifications):** يظهر بسلاسة في زاوية الشاشة ويختفي تلقائياً.
  - **تأثير النبض البصري (FOMO Pulse Animation):** ينبض تلقائياً على مؤشرات العروض التي أوشكت على النفاد (متبقي وجبتان أو أقل).
  - **نسخ كود الحجز بنقرة واحدة (One-Click Copy):** نسخ فوري لكود الاستلام مع إشعار تفاعلي.
  - **حاسبة الخصم الفورية:** تحسب نسبة الخصم وقيمة التوفير المالي تلقائياً أثناء كتابة السعر في نماذج إضافة وتعديل الوجبات.

---

## 🔄 مسار ودورة حياة الحجز والتبرع بالكامل

```
[المطعم] ──> ينشر فائض (بيع مخفض أو تبرع جمعيات) ──> يظهر في المنصة مع فلاتر الأحياء
   │
   ├──> [المستهلك] ──> يحجز ──> يتولد كود فريد (ZAD-XXXXX) ──> يخصم 1 من المخزون
   │       └──> خيار الإلغاء ──> إعادة الوجبة تلقائياً لرصيد المطعم (Restocking)
   │       └──> الاستلام ──> التوجه للمحل، إظهار الكود للكاشير، الدفع كاش
   │
   └──> [الكاشير / المطعم] ──> إدخال الكود في صندوق التحقق السريع ──> اكتمال الطلب
           └──> احتساب الأثر البيئي الفوري (CO2e + توفير المياه)
```

---

## 🌿 معادلات احتساب الأثر البيئي (Environmental Impact)

- **انبعاثات الكربون المتجنبة ($CO_2e$ Saved):** 
  $$\text{CO}_2\text{e} = \text{عدد الوجبات المنقذة} \times 2.5\text{ كجم}$$
- **البصمة المائية التي تم توفيرها (Water Saved):**
  $$\text{Water Saved} = \text{عدد الوجبات المنقذة} \times 1,000\text{ لتر}$$
